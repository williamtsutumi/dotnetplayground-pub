# Migrações do Reddit — PostgreSQL

RedditDbContext usa Npgsql e a conexão DefaultConnection. Os mapeamentos não fixam
schema; o PostgreSQL resolve pelo search_path da conexão (normalmente public).
Os identificadores preservam maiúsculas e minúsculas e precisam de aspas duplas em SQL manual.

InitialPostgreSql cria as sete tabelas, chaves, relacionamentos e índices em um
banco novo. Ela substitui a cadeia anterior do SQL Server; não converte um banco
SQL Server existente nem transfere seus dados ou histórico de migrações.

Os IDs gerados usam GENERATED BY DEFAULT AS IDENTITY; Post.Id é bigint e
Comentario.Id é integer. Textos limitados usam character varying, conteúdo de
posts usa text, booleanos usam boolean e Papel usa smallint. Datas de eventos
usam timestamp with time zone com CURRENT_TIMESTAMP na criação. Valores enviados
pela aplicação para esses campos devem ser UTC. DataNascimento continua date.

A partir da raiz do repositório:

```powershell
dotnet tool install dotnet-ef --version 8.0.29 --tool-path .build-verification/tools

# Gera SQL sem acessar o banco.
.build-verification/tools/dotnet-ef migrations script --project WebApplication1.Infrastructure/WebApplication1.Infrastructure.csproj --startup-project WebApplication1.Infrastructure/WebApplication1.Infrastructure.csproj --context RedditDbContext

# Configure a conexão real antes de aplicar em um banco novo.
$env:ConnectionStrings__DefaultConnection = 'Host=localhost;Port=5432;Database=Reddit;Username=postgres;Password=<senha>'
.build-verification/tools/dotnet-ef database update --project WebApplication1.Infrastructure/WebApplication1.Infrastructure.csproj --startup-project WebApplication1.Infrastructure/WebApplication1.Infrastructure.csproj --context RedditDbContext
```

A factory lê a variável de ambiente e usa uma conexão PostgreSQL local sem senha
como fallback para geração offline. Ela não lê appsettings do projeto Web.
A aplicação usa DefaultConnection da configuração habitual.
Nenhuma migração é aplicada automaticamente na inicialização da aplicação.

Para copiar somente os dados de um SQL Server existente depois de criar as tabelas,
use o [utilitário DataMigration](../DataMigration/README.md).
