Este é um clone Reddit.

Este projecto tem apenas um objectivo de estudos e aprendizagem. Eu quero implementar coisas que eu só conheço a teoria, e também aprender coisas que estão na minha lista de estudo TO-DO por muito tempo. Provavelmente descobrirei coisas para aprender que ainda nem sei que existem.

Nem tudo o que implemento aqui fará sentido para as circunstâncias. É literalmente o meu projecto Playground.

Estou documentando o desenvolvimento deste projeto em si mesmo via Posts e Comunidades, e portanto, é auto-documentante (se este termo existir).

Eu estive usando IA com poucas instruções técnicas por duas razões. Primeiro, para ver como AI pode lidar com o desenvolvimento de um projeto inteiro de zero. Segundo, deixar o código ficar mais complexo e mais difícil de manter de propósito, porque simula mais realistamente um produto real, mantido por várias pessoas ao longo de muitos anos.

Inicialmente, eu tinha criado este projeto para aprender a implantar um site, especialmente em AWS. Mais tarde, também incluí alguns testes unitários com xUnit e um pipeline CI/CD com Jenkins. Mas, a parte dos testes da unidade ainda está na minha lista para estudar corretamente. Quanto mais trabalho neste projecto, mais tempo fica a minha lista de tarefas.
